# Фрактал Мандельброта в ASCII

Програма малює множину Мандельброта символами в консолі. Для кожної точки комплексної площини вона рахує, скільки ітерацій точка «тримається» в множині, і перетворює це число на символ.

## Код програми

```python
def escape_time(c, max_iter=50):
    """Скільки кроків точка c 'тримається' в множині Мандельброта."""
    z = 0
    for i in range(max_iter):
        z = z * z + c
        if abs(z) > 2:
            return i
    return max_iter


def pick_char(i, max_iter=50):
    """Перетворює кількість ітерацій на символ: чим далі, тим 'щільніше'."""
    if i == max_iter:
        return "█"
    palette = " .:-=+*#%@"
    return palette[i * len(palette) // max_iter]


def render(width=80, height=32):
    """Малює фрактал рядок за рядком."""
    rows = []
    for y in range(height):
        row = ""
        for x in range(width):
            c = complex(-2.2 + 3.2 * x / width, -1.2 + 2.4 * y / height)
            row += pick_char(escape_time(c))
        rows.append(row)
    return "\n".join(rows)


print(render())
#author Khrystyna Prykhodko
```

## Документація функцій

### `escape_time(c, max_iter=50)`

**Опис**

Обчислює, скільки ітерацій формули `z = z² + c` (починаючи з `z = 0`) потрібно, щоб модуль `z` перевищив 2. Якщо за `max_iter` кроків цього не сталося, вважається, що точка належить множині Мандельброта.

**Параметри**

| Параметр   | Тип       | За замовчуванням | Опис                                   |
|------------|-----------|------------------|----------------------------------------|
| `c`        | `complex` | —                | Точка комплексної площини для перевірки |
| `max_iter` | `int`     | `50`             | Максимальна кількість ітерацій          |

**Що повертає**

`int` — номер ітерації, на якій `|z| > 2`, або `max_iter`, якщо точка не «втекла».

**Приклад використання**

```python
print(escape_time(0))      # 50 — точка в множині
print(escape_time(1))      # 2  — швидко «втікає»
print(escape_time(1, 10))  # 2  — те саме з іншим max_iter
```

---

### `pick_char(i, max_iter=50)`

**Опис**

Перетворює кількість ітерацій на символ для виведення. Точки, що належать множині, позначаються повним блоком `█`. Решта отримує символ із палітри ` .:-=+*#%@` залежно від значення `i`.

**Параметри**

| Параметр   | Тип   | За замовчуванням | Опис                                                      |
|------------|-------|------------------|-----------------------------------------------------------|
| `i`        | `int` | —                | Кількість ітерацій (результат `escape_time`)              |
| `max_iter` | `int` | `50`             | Максимальна кількість ітерацій (має збігатися з `escape_time`) |

**Що повертає**

`str` — один символ: `█` для точок усередині множини або символ із палітри для інших.

**Приклад використання**

```python
print(pick_char(0))    # ' ' — пробіл (точка одразу «втекла»)
print(pick_char(25))   # '+' — середня щільність
print(pick_char(50))   # '█' — точка в множині
```

---

### `render(width=80, height=32)`

**Опис**

Проходить по сітці `width × height` точок, відображає кожну на область комплексної площини (`Re` від -2.2 до 1.0, `Im` від -1.2 до 1.2), викликає `escape_time` і `pick_char` та збирає результат у багаторядковий текст.

**Параметри**

| Параметр | Тип   | За замовчуванням | Опис                          |
|----------|-------|------------------|-------------------------------|
| `width`  | `int` | `80`             | Кількість символів у рядку    |
| `height` | `int` | `32`             | Кількість рядків              |

**Що повертає**

`str` — готове зображення фрактала: `height` рядків по `width` символів, розділених `\n`.

**Приклад використання**

```python
picture = render(40, 16)
print(picture)

# Перевірка розмірів
lines = picture.split("\n")
print(len(lines))     # 16
print(len(lines[0]))  # 40
```
